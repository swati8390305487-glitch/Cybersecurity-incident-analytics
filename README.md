# Cybersecurity-Incident-Analytics

## Descriptions 

Developed an interactive Power BI Cybersecurity Incident Analytics Dashboard to analyze cybersecurity incidents, attack patterns, financial losses, and affected users. The dashboard uses KPI cards, trend analysis, attack-type distribution, industry-wise financial loss, and interactive filters to provide a clear executive-level view of cybersecurity risks.

Key Features
📊 Incident trends by year
🛡️ Analysis of attack types such as Malware, Phishing, DDoS, Ransomware, SQL Injection, and Insider Threat
💰 Financial loss analysis by target industry
🌍 Country-wise incident analysis
👥 Affected users and incident impact
⏱️ Average incident resolution time
🔎 Interactive filters for Year, Country, Attack Type, and Target Industry
📈 KPI cards for quick executive-level insights
